## Run Locally

Install dependencies:

```bash
pip install -r backend/requirements.txt
```

Start the backend:

```bash
cd backend
uvicorn main:app --reload
```

Open API documentation:

http://127.0.0.1:8000/docs

## Run Tests

```bash
cd backend
python -m pytest -v
```
